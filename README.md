<h1 align="center">
  Quem Sou Eu</h1>

<p align="center">
  Neste projeto desenvolvi uma página pessoal intitulada <strong>"Quem Sou Eu"</strong>, com o objetivo de apresentar um pouco sobre minha trajetória, meus objetivos e minha transição para a área da programação. Durante o desenvolvimento, pratiquei conceitos de HTML e CSS, aprimorando a estrutura do código, a organização do layout e a responsividade da página. </p>

<p align="center">
  Este projeto foi desenvolvido com os conhecimentos adquiridos ao longo da formação no <a href="https://lp6.rodolfomori.com.br/cap-org-a-v1/?utm_campaign=encurtadoraprendacomigo&_v=019f72c3-1689-7b02-8b8d-d1359e8a8949&_p=019e5077-bd01-7420-900d-fc6e5b6f12af&_c=412ee7fe-d121-4828-b6ac-f8e0cf60bd16&_l=019f72c3-1623-75b1-b90e-8b3bb4d734d9">DevClub</a>. </p>
